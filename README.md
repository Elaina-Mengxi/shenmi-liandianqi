# 神秘连点器

一个通过安卓无障碍服务，在两个选定位置之间循环点击的小工具。

本次发布使用保留的**原始 1.0 安装包**。手机上的应用名称为“暂停循环”，支持 Android 7.0 及以上。

## 点击时序

| 参数 | 固定值 |
| --- | --- |
| 按住时间 | 0.03 秒 |
| 第一点（暂停）完成后等待 | 0.2 秒 |
| 第二点（继续）完成后等待 | 2 秒 |
| 启动倒计时 | 3 秒 |

按下和抬起在同一个坐标，不滑动。等待从前一个手势的完成回调开始计算，实际执行会受到系统调度影响。没有随机时序、随机坐标、图像识别或自动返回。

## 使用

1. 安装并打开“暂停循环”，开启对应的无障碍服务。系统若限制开启，请在应用信息页检查是否需要允许受限设置。
2. 显示悬浮控制条，切换到需要操作的页面。
3. 在正在运行的状态选取第一个暂停位置，选点只记录坐标，不会触发目标按钮。
4. 手动暂停目标页面，再选取第二个继续位置。
5. 手动恢复目标页面的运行状态，再启动循环；倒计时 3 秒后从暂停点击开始。
6. 切换页面或调整位置前先停止循环。屏幕方向变化后需要重新选点。

如果手机上已安装版本号更高的测试版，系统可能不允许直接覆盖降级；需要先卸载测试版，再安装原版并重新授权、选点。

## 已知问题

在微信的部分页面上，模拟点击可能意外进入设置页，原因尚未确定。遇到这种情况：**先停止自动循环，手动返回并恢复正确页面，再重新启动循环。**本版不自动恢复，不能保证兼容所有页面或机型。

## 权限与隐私

通过安卓无障碍服务的 `dispatchGesture()` 发送点击，无需 Root、USB 调试、无线调试或 Shizuku。

应用没有网络权限，不读取界面文字、不截图、不录屏，也不上传数据。选点只保存在服务内存中，服务重新连接后需要重新选点。

## 从源码构建（Windows）

需要 JDK 17、Android SDK Platform 35 和 Build Tools 35.0.0：

```powershell
$env:JAVA_HOME = 'C:\Java\jdk-17'
$env:ANDROID_SDK_ROOT = 'C:\Android\Sdk'
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

也可以通过 `-JdkPath`、`-SdkPath`、`-BuildToolsPath` 和 `-PlatformJar` 参数指定工具。产物位于 `out/PauseLoop-v1.0.apk`。

脚本会在 `out/` 下生成仅供本地构建使用的开发签名密钥。该密钥不包含在仓库中；自行构建的 APK 使用不同签名时，无法直接覆盖安装历史原版。
