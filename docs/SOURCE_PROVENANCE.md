## 还原过程

最初的 Java 源文件未单独保存。使用 [JADX](https://github.com/skylot/jadx) 1.5.6 对上述本项目 APK 进行反编译，再整理为可阅读、可编译的 Java 源码：

- 将编译器生成的匿名类、捕获字段和合成方法恢复为等价的 Java lambda/回调写法。
- 用 Android 常量替换窗口类型、布局标志、事件类型等数值。
- 保留原来的界面文字、选点方式、按钮行为、启动倒计时和固定点击时序。
- 根据安装包元数据重建 Manifest 和无障碍配置；服务说明文字重新整理为当前仓库的功能说明。

仓库仅包含本项目自己的应用代码，不包含微信或其他第三方应用的反编译代码，也不包含 JADX 工具分发文件。

## 已核对的内容

1. 原始安装包的版本、文件哈希和签名校验。
2. 还原源码的 Android Java 编译、DEX 生成、打包和本地开发签名校验。
3. 点击使用单点静止 Path，按住30毫秒。
4. 下一次点击在完成回调后安排：暂停后200毫秒，继续后2000毫秒。
5. 首次倒计时3000毫秒；试跑3次；停止时取消后续回调，旧 token 不继续运行。
6. 不含随机化、截图、OCR、联网或自动返回逻辑。

这些检查不构成源码与原安装包的逐字节等价证明，也不是新的跨机型真机测试。仍需保留 README 中的已知问题说明。

## 签名区别

原始安装包保留历史签名。仓库不公开对应私钥。

构建脚本在本机 `out/` 生成独立开发密钥，自编译 APK 默认使用该密钥。因此自编译包与原始 Release 包不能保证能够直接覆盖安装；`out/` 和密钥文件均在 `.gitignore` 中排除。
